
# VIHA AI Assistant

## About the Project
VIHA is an AI-powered personal assistant
built using n8n and Generative AI.

## Features
- AI-powered conversations
- Automated responses
- Workflow automation
- AI integration using API

## Technologies Used
- n8n
- Generative AI
- OpenAI API
- JSON

## Workflow
The project uses n8n nodes to connect
the user input, AI model, and response.

## Installation
1. Download the workflow JSON file.
2. Open your n8n instance.
3. Import the workflow JSON.
4. Configure your own API credentials.
5. Execute the workflow.
